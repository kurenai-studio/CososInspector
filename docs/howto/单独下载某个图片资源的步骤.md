# 单独下载某个图片资源的步骤

适用于 Egret 5.x 引擎游戏页（如 bydrqp 捕鱼），通过 Cocos Inspector 扩展 + MCP server 拉取场景图片原始字节。

## 前置条件

1. Chrome/Edge 加载扩展（`--load-extension` + `--remote-debugging-port=9222`）
2. MCP server 已配 `~/.claude.json`（CDP 模式 `COCOS_USE_CDP=1` + `COCOS_CDP_PORT=9222`）
3. 依赖已装：`tools/mcp-cocos-inspector/` 下 `npm install`
4. 游戏页打开，`window.__cocosInspectorApi` 就绪

> 一键启动：`node tools/verify-egret-cdp.mjs https://qp.bydrqp.com/bkby/platform/1020/index.html`

## 图片资源两类来源

| 类型 | RES alias 命名 | 实际文件 |
|------|---------------|---------|
| 单图 | `xxx_png` / `xxx_jpg` | `xxx.png` / `xxx.jpg` |
| 图集子图 | `xxx_json#0` 等 | 父级 `xxx_json` + `xxx_png` |

## 操作步骤

### Step 1：列资源找图片

MCP 工具：

```
mcp__cocos-inspector__cocos_list_resources
```

或浏览器 F12 console：

```js
__cocosInspectorApi.listResources(500)
```

从返回的 `items` 里筛 `type === 'image'`，记下 `name`（如 `loading_bg_new_jpg`）。

### Step 2：下载单图

MCP 方式：

```
mcp__cocos-inspector__cocos_download_resource(name="loading_bg_new_jpg", outPath="D:/work/img/loading_bg_new.jpg")
```

console 方式：

```js
const dl = await __cocosInspectorApi.downloadResource('loading_bg_new_jpg');
const buf = Buffer.from(dl.base64, 'base64');
// 写盘（Node 环境）或 new Blob + download（浏览器）
```

### Step 3：图集子图（可选）

若需子图（图集中的一块），用 `cocos_download_texture`：

```
mcp__cocos-inspector__cocos_download_texture(nodeId="egret-16")
```

该工具按节点 `$bitmapX/Y/W/H` 从图集裁剪出子图，输出独立 PNG。

## 常见问题

| 问题 | 解决 |
|------|------|
| fetch 失败（CORS/404） | 桥接自动回退：从已解码 HTMLImageElement 整图导出 |
| 列表里只有 `_json` 没有 `_png` | 子图引用，先找父级 `_json` 同名 `_png` |
| 图片在缓存未到 RES | 用 `cocos_list_sprites` 看场景节点纹理，直接 `cocos_download_texture(nodeId)` |
