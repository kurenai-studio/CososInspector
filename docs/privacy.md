# Cocos Inspector 3 — 隐私政策

**生效日期：** 2026-08-11  
**产品：** Chrome 扩展「Cocos Inspector 3」

本扩展面向游戏开发者，在浏览器打开的试玩页 / H5 游戏页上查看场景节点、组件与资源，辅助调试。我们重视隐私，说明如下。

## 我们收集什么

**本扩展不会把你的浏览数据上传到开发者服务器。** 不设账号体系，不采集姓名、邮箱、支付信息。

在本地浏览器内，扩展可能访问：

| 数据类型 | 用途 | 是否离开本机 |
|----------|------|----------------|
| 当前标签页 URL / 标题 | 识别试玩页、面板展示 | 默认否 |
| 页面中的游戏运行时对象（如 `cc` / `egret`） | 构建节点树、预览资源 | 否（仅页内） |
| 可选：可见标签页截图 | 用户主动截屏时 | 否（用户保存） |
| 扩展 `storage` 中的开关（如 Pixi 探测） | 记住偏好 | 否 |

## 本机开发桥接（可选）

若你在本机运行配套 MCP / 桥接进程，扩展可能连接：

`ws://127.0.0.1:17373`（仅本机回环地址）

用于把当前页的调试能力提供给本机开发工具。该连接：

- **不会**发往公网
- 仅在本机已启动桥接时生效
- 不使用则不会产生相关数据交换

Chrome 网上应用店安装包**不包含** MCP 服务端；MCP 仅存在于开源仓库，供开发者自行运行。

## 权限说明

| 权限 | 原因 |
|------|------|
| 访问 http/https 页面 | 试玩页域名不固定，需在用户打开的游戏页注入探测脚本；未检测到引擎时不启动完整面板 |
| `tabs` | 标签信息与截屏等调试能力 |
| `activeTab` / `storage` | 当前页交互与偏好存储 |

## 数据分享

我们不出售、不出租用户数据。不向第三方广告或分析平台发送浏览内容。

## 儿童隐私

本产品面向开发者工具场景，不面向 13 岁以下儿童。

## 变更

隐私政策更新时，将同步修改本页面并调整「生效日期」。继续使用即表示知悉更新后的政策。

## 联系

如有隐私相关问题，请通过 GitHub Issues 联系：  
https://github.com/shinjiyu/CososInspector/issues

扩展内「反馈」仅在用户主动操作时生成**本地**诊断日志文本（视口尺寸、扩展版本、页面 URL、按键/resize 事件摘要等），不自动上传。用户可将该文件自行发送给我们用于排障。

（若你使用的是社区 fork，请改用对应仓库的 Issues。）
